# codex汉化增强plus版 1.0.1

This release focuses on Windows update stability and the desktop model bridge.

## Highlights

- Reworked the Windows watcher host so background repair and update checks run as a service without flashing a console window.
- Treated a missing GitHub Release as "no published release found" instead of a failed hot update, while keeping repair checks active.
- Kept stale Release 404 logs from making the watcher health panel report a false warning.
- Launched manual update checks through a hidden Node process on Windows instead of a visible helper window.
- Moved watcher and manual update working directories outside the source tree before replacement so Windows does not lock the directory being updated.
- Kept the tray restore, DeepSeek, Qwen, Zhipu GLM, and native Codex switching fixes from the current desktop build.

## Notes

- Hot update downloads the GitHub source archive for the selected release tag, installs dependencies, builds the runtime, and reapplies the desktop patch.
- It does not download a DLL patch. On Windows, the only compiled executable owned by this layer is the watcher service host.
