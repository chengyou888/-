# codex汉化增强plus版 1.0.2

This release removes the remaining Windows console-window flashes from the background updater and desktop launcher.

## Highlights

- Starts the watcher service child `node.exe` with `CREATE_NO_WINDOW`.
- Starts the desktop Codex app-server wrapper target with `CREATE_NO_WINDOW`.
- Reads Windows proxy settings through hidden `reg.exe` child processes, avoiding the black console flash during Codex startup or user login.

## Notes

- The watcher is still a Windows service and remains visible only in Services / Task Manager.
- No global Codex config is changed by this update.
